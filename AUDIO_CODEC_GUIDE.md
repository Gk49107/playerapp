# Audio Codec Support Guide\n\n## Overview\n\nThis video player is built on top of ExoPlayer, Google's media player library that provides excellent support for advanced audio codecs including EAC3, AC3, FLAC, and Opus.\n\n## Supported Audio Codecs\n\n### 1. EAC3 (Enhanced AC-3)\n\n**Format:** Dolby Digital Plus / E-AC-3\n- **Container:** MP4, MKV, TS\n- **Extension:** .ec3, .eac3, .mp4 (if contains EAC3)\n- **Channels:** Up to 5.1 surround (or stereo)\n- **Bitrate:** 64 Kbps - 5.1 Mbps\n- **Quality:** Excellent (compressed surround)\n- **Support:** Fully supported via Android native decoder\n\n**When to use:**\n- High-quality streaming with smaller file sizes\n- Streaming services (Netflix, Amazon Prime Video)\n- Professional video production\n- Broadcast content\n\n**Example:**\n```\nvideo.mp4 - Audio: Enhanced AC-3 5.1 @ 448 Kbps\n```\n\n### 2. AC3 (Dolby Digital)\n\n**Format:** Dolby Digital / AC-3\n- **Container:** MP4, MKV, TS, AVI\n- **Extension:** .ac3, .mp4 (if contains AC3)\n- **Channels:** Up to 5.1 surround\n- **Bitrate:** 192 - 640 Kbps\n- **Quality:** Very good (compressed surround)\n- **Support:** Fully supported via Android native decoder\n\n**When to use:**\n- DVD and Blu-ray content\n- Professional video files\n- Backward compatibility with older systems\n\n### 3. AAC (Advanced Audio Coding)\n\n**Format:** Advanced Audio Coding\n- **Container:** MP4, MKV, M4A\n- **Extension:** .aac, .m4a, .mp4 (if contains AAC)\n- **Channels:** Up to 7.1 surround\n- **Bitrate:** 96 - 320 Kbps (typical)\n- **Quality:** Good (compressed)\n- **Support:** Native Android support\n\n**When to use:**\n- iTunes and Apple ecosystem\n- Mobile-optimized videos\n- Standard streaming\n- General audio playback\n\n### 4. MP3 (MPEG-1 Audio Layer III)\n\n**Format:** MPEG-1 Audio Layer III\n- **Container:** MP3, MP4, MKV\n- **Extension:** .mp3\n- **Channels:** Mono, Stereo\n- **Bitrate:** 128 - 320 Kbps (typical)\n- **Quality:** Good (compressed)\n- **Support:** Native Android support (universal codec)\n\n**When to use:**\n- Music videos\n- Podcasts\n- Universal compatibility requirement\n- Legacy content\n\n### 5. FLAC (Free Lossless Audio Codec)\n\n**Format:** Free Lossless Audio Codec\n- **Container:** FLAC, MKV, OGG\n- **Extension:** .flac, .ogg\n- **Channels:** Up to 8 channels\n- **Bitrate:** Variable (depends on content)\n- **Quality:** Lossless (bit-perfect)\n- **Support:** Supported via ExoPlayer FLAC extension\n\n**When to use:**\n- Audiophile/high-fidelity content\n- Professional audio archiving\n- Music with maximum quality\n- When file size is not a constraint\n\n**Note:** Requires `exoplayer-flac` dependency (included in this project)\n\n### 6. Opus\n\n**Format:** Opus Audio Codec\n- **Container:** WebM, Ogg, MKV\n- **Extension:** .opus, .webm, .ogg\n- **Channels:** Up to 8 channels\n- **Bitrate:** 6 - 510 Kbps (very flexible)\n- **Quality:** Excellent (modern compression)\n- **Support:** Supported via ExoPlayer Opus extension\n\n**When to use:**\n- Modern web content\n- VR and immersive audio\n- Bandwidth-constrained environments\n- Latest streaming standards\n- Speech and music (excellent quality at low bitrates)\n\n**Note:** Requires `exoplayer-opus` dependency (included in this project)\n\n## Audio Codec Detection\n\nThe player automatically detects audio codecs from:\n1. File extension\n2. Container format metadata\n3. Audio track information\n\n### How to Check Codec of Your File\n\n**Using FFmpeg/FFprobe:**\n```bash\nffprobe -v error -select_streams a:0 -show_entries stream=codec_name,codec_long_name -of default=noprint_wrappers=1:nokey=1:noinfer_type=0 video.mp4\n```\n\n**Output example:**\n```\naac\nAdvanced Audio Coding\n```\n\n**Using MediaInfo:**\n```bash\nmediainfo video.mp4\n```\n\n## Codec CPU usage\n- ✓ Better battery life\n- ✓ Smoother playback\n\n### Software Decoding\nFLAC and Opus may use software decoders on some devices:\n- May use more CPU\n- Still generally acceptable for typical video playback\n- ExoPlayer handles this efficiently\n\n## File Format Recommendations\n\n### For Streaming (over network)\n**Best:** MP4 with AAC or EAC3\n- Streaming-friendly container\n- Wide device support\n- Good compression\n- Fast seeking\n\n### For Local Storage\n**Best:** MKV with FLAC or Opus\n- Excellent codec support\n- Can contain multiple audio tracks\n- Efficient container\n- Flexible compression\n\n### For Maximum Compatibility\n**Best:** MP4 with AAC or MP3\n- Universal device support\n- Proven compatibility\n- Hardware acceleration on all devices\n\n### For Best Quality\n**Best:** MKV with FLAC\n- Lossless quality\n- Excellent compression\n- Professional grade\n- Can include multiple formats\n\n## Troubleshooting Audio Codec Issues\n\n### Issue: \"Audio track not playing\"\n\n**Diagnosis:**\n```bash\n# Check codec\nffprobe -v error -select_streams a:0 -show_entries stream=codec_name video.mp4\n\n# Check bitrate\nffprobe -v error -select_streams a:0 -show_entries stream=bit_rate video.mp4\n```\n\n**Solutions:**\n1. Verify codec is listed in SUPPORTED_AUDIO_CODECS\n2. Check Android version (minimum API 21)\n3. Ensure ExoPlayer dependencies are included in build.gradle\n4. Try converting to AAC: `ffmpeg -i video.mp4 -c:v copy -c:a aac output.mp4`\n\n### Issue: \"Audio is choppy or stutters\"\n\n**Causes:**\n- Low device RAM\n- High bitrate codec on weak CPU\n- Storage I/O issues\n\n**Solutions:**\n1. Close other apps\n2. Reduce video quality if possible\n3. Use AAC instead of FLAC for playback\n4. Store files on faster storage (avoid SD card for local playback)\n\n### Issue: \"Multi-channel audio plays as stereo\"\n\n**Note:** This is normal if device doesn't support surround speakers.\n\n**Solutions:**\n1. Connect external surround speakers/headphones\n2. Enable spatial audio if device supports it\n3. Convert to stereo for devices without surround support\n\n## Converting Between Codecs\n\nUsing FFmpeg:\n\n```bash\n# Convert to EAC3\nffmpeg -i input.mp4 -c:v copy -c:a eac3 -b:a 448k output.mp4\n\n# Convert to FLAC\nffmpeg -i input.mp4 -c:v copy -c:a flac output.mkv\n\n# Convert to Opus\nffmpeg -i input.mp4 -c:v copy -c:a libopus -b:a 128k output.webm\n\n# Convert to AAC (most compatible)\nffmpeg -i input.mp4 -c:v copy -c:a aac -b:a 192k output.mp4\n```\n\n## Additional Resources\n\n- [ExoPlayer Documentation](https://exoplayer.dev/supported-formats.html)\n- [Android Media Format Support](https://developer.android.com/guide/topics/media/media-formats)\n- [FFmpeg Documentation](https://ffmpeg.org/documentation.html)\n- [Codec Comparison](https://en.wikipedia.org/wiki/Audio_codec)\n\n## Notes\n\n- This app requires Android API 21+ (Android 5.0 Lollipop)\n- All listed codecs are supported on Android 5.0+\n- Hardware support varies by device manufacturer\n- Some older devices may not support all codecs\n- ExoPlayer handles fallbacks gracefully\n
