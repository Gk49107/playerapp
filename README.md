# Advanced Video Player with EAC3 Audio Support\n\nA React Native video player application with full support for EAC3, AC3, AAC, MP3, FLAC, and Opus audio codecs. Features include play/pause controls, seek functionality, volume control, subtitle support, fullscreen mode, and playlist management.\n\n## Features\n\n### Audio Codec Support\n- **EAC3 (Enhanced AC-3)** - Primary enhanced audio format up to 5.1 surround\n- **AC3** - Standard 5.1 surround sound\n- **AAC** - Advanced Audio Coding\n- **MP3** - MPEG-1 Audio Layer III\n- **FLAC** - Free Lossless Audio Codec\n- **Opus** - Modern open-source audio codec\n\n### Player Features\n- ▶️ Play/Pause controls\n- ⏩ Seek and progress bar with timeline\n- 🔊 Volume control slider\n- 📝 Subtitle support (SRT, VTT, TTML formats)\n- ⛶ Fullscreen mode with auto-rotation\n- 📋 Playlist management with multiple videos\n- ⚡ Playback speed control (0.5x, 1x, 1.5x, 2x)\n- ⏪⏩ 10-second rewind/forward buttons\n- 🎬 Video status indicators\n\n## Tech Stack\n\n- **React Native** 0.73.0\n- **TypeScript** 5.0\n- **react-native-video** 5.2.1 - Video playback\n- **ExoPlayer** 2.18.7 - Advanced codec support (EAC3, AC3, FLAC, Opus)\n- **@react-native-community/slider** - Seek and volume controls\n- **react-native-orientation-locker** - Fullscreen handling\n- **react-native-fs** - File system access\n\n## Project Structure\n\n```\nVideoPlayerApp/\n├── src/\n│   ├── components/\n│   │   ├── VideoPlayer.tsx      # Details\n\n### Why ExoPlayer?\n\nExoPlayer is Google's open-source media player library that provides excellent support for advanced audio codecs:\n\n- **EAC3 & AC3**: Full support via Android native decoder\n- **FLAC**: Lossless audio support\n- **Opus**: Modern codec for bandwidth efficiency\n- **Multi-track audio**: Support for multiple audio streams\n- **DRM protection**: Optional DRM support\n\n### Enabling Codec Support\n\nThe following dependencies enable codec support (in `android/app/build.gradle`):\n\n```gradle\n// Core ExoPlayer\nimplementation \"com.google.android.exoplayer:exoplayer-core:2.18.7\"\n\n// Optional codec extensions\nimplementation \"com.google.android.exoplayer:exoplayer-opus:2.18.7\"\nimplementation \"com.google.android.exoplayer:exoplayer-flac:2.18.7\"\n```\n\n## Usage Examples\n\n### Play a Single Video\n\n```typescript\nimport VideoPlayer from './components/VideoPlayer';\nimport { VideoItem } (.webm)\n- OGG (.ogg)\n- TS (.ts)\n\n### Subtitle Formats\n- SubRip (.srt)\n- WebVTT (.vtt)\n- TTML (.ttml, .xml)\n\n## Troubleshooting\n\n### APK Build Issues\n\n**Issue: \"Multiple dex files define Lcom/google/android/exoplayer2/...\"**\n\n*Solution:* Add multidex support in `android/app/build.gradle`:\n```gradle\ndefaultConfig {\n    multiDexEnabled true\n}\n```\n\n**Issue: \"Could not resolve com.google.android.exoplayer:exoplayer\"**\n\n*Solution:* Ensure `mavenCentral()` is in repositories:\n```gradle\nallprojects {\n    repositories {\n        google()\n        mavenCentral()\n    }\n}\n```\n\n### Codec Not Working\n\n**EAC3/AC3 audio plays but no sound:**\n- Verify device supports the codec (most modern Android devices do)\n- Check that the video file actually contains the codec (use `ffprobe` to verify)\n\n**FLAC/Opus doesn't play:**\n- Ensure the codec extension libraries are included in `build.gradle`\n- Rebuild the APK after adding dependencies\n\n## Performance
