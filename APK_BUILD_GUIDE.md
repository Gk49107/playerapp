# APK Build Guide\n\n## Overview\n\nThis guide covers building, signing, and distributing APKs for the VideoPlayerApp.\n\n## Prerequisites\n\n- Android SDK (API 34)\n- Android NDK (version 25.1.8937393)\n- Java Development Kit (JDK 11+)\n- Gradle (typically comes with Android SDK)\n\n## Build Types\n\n### 1. Debug APK (For Testing)\n\nDebug APKs are unsigned and optimized for development.\n\n**Build command:**\n```bash\ncd VideoPlayerApp/android\n./gradlew assembleDebug\n```\n\n**Output location:**\n```\nVideoPlayerApp/android/app/build/outputs/apk/debug/app-debug.apk\n```\n\n**Install on device:**\n```bash\nadb install app-debug.apk\n```\n\n**When to use:**\n- Development and testing\n- Quick iterations\n- Testing specific devices\n\n---\n\n### 2. Release APK (For Distribution)\n\nRelease APKs are optimized and can be signed for distribution.\n\n**Build command (unsigned):**\n```bash\ncd VideoPlayerApp/android\n./gradlew assembleRelease\n```\n\n**Output location:**\n```\nVideoPlayerApp/android/app/build/outputs/apk/release/app-release-unsigned.apk\n```\n\n**When to use:**\n- Publishing to Play Store\n- Distribution to users\n- Production deployment\n\n---\n\n### 3. Split APKs (Architecture-Specific)\n\nReduce APK size by creating separate APKs for different CPU architectures.\n\n**Supported architectures:**\n- `armeabi-v7a` - 32-bit ARM (older devices)\n- `arm64-v8a` - 64-bit ARM (modern devices)\n- `x86` - Intel 32-bit\n- `x86_64` - Intel 64-bit\n\n**Build split APKs:**\n```bash\ncd android\n./gradlew assembleRelease\n```\n\n**Output locations:**\n```\napp/build/outputs/apk/release/app-release-armeabi-v7a.apk\napp/build/outputs/apk/release/app-release-arm64-v8a.apk\napp/build/outputs/apk/release/app-release-x86.apk\napp/build/outputs/apk/release/app-release-x86_64.apk\n```\n\n**Note:** If universal APK is preferred (not split by architecture):\n- Modify `android/app/build.gradle`:\n  ```gradle\n  splits {\n    abi {\n      universalApk true  // Enable universal APK\n    }\n  }\n  ```\n\n---\n\n## Signing APKs\n\n### Step 1: Create a Keystore\n\nA keystore is required to sign release APKs.\n\n**Generate keystore:**\n```bash\nkeytool -genkey -v -keystore my-key.keystore \\\n  -keyalg RSA \\\n  -keysize 2048 \\\n  -validity 10000 \\\n  -alias my-key-alias\n```\n\n**You'll be prompted for:**\n- Keystore password\n- Key password\n- Key information (name, organization, location)\n\n**Example:**\n```\nKeytool command: keytool -genkey -v -keystore VideoPlayer.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias videoplayer\nKeystory password: (enter secure password)\nKey password: (same as keystore or different)\nWhat is your first and last name?\n  [Unknown]: John Developer\nWhat is the name of your organizational unit?\n  [Unknown]: Development\nWhat is the name of your organization?\n  [Unknown]: My Company\nWhat is the name of your City or Locality?\n  [Unknown]: New York\nWhat is the name of your State or Province?\n  [Unknown]: NY\nWhat is the two-letter country code for this unit?\n  [Unknown]: US\n```\n\n### Step 2: Configure Signing in build.gradle\n\nEdit `android/app/build.gradle`:\n\n```gradle\nsigningConfigs {\n    release {\n        storeFile file(\"../VideoPlayer.keystore\")\n        storePassword \"your_keystore_password\"\n        keyAlias \"videoplayer\"\n        keyPassword \"your_key_password\"\n    }\n}\n\nbuildTypes {\n    release {\n        signingConfig signingConfigs.release\n        minifyEnabled true\n        proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'\n    }\n}\n```\n\n### Step 3: Build Signed Release APK\n\n```bash\ncd android\n./gradlew assembleRelease\n```\n\n**Output:**\n```\napp/build/outputs/apk/release/app-release.apk (signed)\n```\n\n### Alternative: Sign APK Manually\n\nIf you already have an unsigned APK:\n\n```bash\njarsigner -verbose -sigalg SHA256withRSA -digestalg SHA-256 \\\n  -keystore VideoPlayer.keystore \\\n  app-release-unsigned.apk videoplayer\n```\n\nThen verify:\n```bash\njarsigner -verify -verbose -certs app-release-unsigned.apk\n```\n\n---\n\n## APK Size Optimization\n\n### Size Breakdown (Typical)\n\n| Component | Size |\n|-----------|------|\n| Base React Native | ~10 MB |\n| ExoPlayer | ~8-10 MB |\n| Dependencies | ~5-7 MB |\n| App Code | ~2-3 MB |\n| Resources | ~1-2 MB |\n| **Total** | **~26-32 MB** |\n\n### Reduce Size\n\n**1. Enable ProGuard Minification (already enabled in release builds)**\n```gradle\nminifyEnabled true\nproguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'\n```\n\n**2. Use Split APKs**\n```gradle\nsplits {\n    abi {\n        enable true\n        universalApk false  // Don't create universal APK\n    }\n}\n```\n\nThis reduces each APK to ~10-15 MB instead of ~26-32 MB.\n\n**3. Remove Unnecessary Dependencies**\n\nCheck `android/app/build.gradle` for unused dependencies.\n\n**4. Compress Resources**\n\n```gradle\nbuildTypes {\n    release {\n        shrinkResources true  // Remove unused resources\n        minifyEnabled true\n    }\n}\n```\n\n---\n\n## Installation Methods\n\n### Via ADB (Development)\n\n```bash\n# Install debug APK\nadb install app-debug.apk\n\n# Install and run\nadb install -r app-debug.apk  # -r = replace existing\n\n# Uninstall\nadb uninstall com.videoplayer\n```\n\n### Via USB (Testing)\n\n1. Connect Android device via USB\n2. Copy APK to device\n3. Use file manager to navigate and tap APK\n4. Follow installation prompts\n\n### Via Google Play Store (Distribution)\n\n1. Create Google Play Developer account ($25 one-time fee)\n2. Sign release APK or AAB (Android App Bundle)\n3. Upload to Play Console\n4. Configure store listing\n5. Submit for review\n\n---\n\n## Troubleshooting Build Issues\n\n### Issue: \"BUILD FAILED\"\n\n**Check errors:**\n```bash\ncd android\n./gradlew assembleDebug -x lint\n```\n\n### Issue: \"error: SDK location not found. Define location with sdk.dir in the local.properties file\"\n\n**Solution:**\n1. Create `android/local.properties`:\n```properties\nsdk.dir=/path/to/android-sdk\nndk.dir=/path/to/android-ndk\n```\n\n2. Or set environment variable:\n```bash\nexport ANDROID_HOME=/path/to/android-sdk\n```\n\n### Issue: \"error: Attribute application@icon references an unknown resource\"\n\n**Solution:** Ensure icon files exist in `android/app/src/main/res/mipmap-*` directories\n\n### Issue: \"error: Multiple dex files define Lcom/google/android/exoplayer2/...\"\n\n**Solution:** Add to `android/app/build.gradle`:\n```gradle\ndefaultConfig {\n    multiDexEnabled true\n}\n```\n\n### Issue: \"Build takes too long\"\n\n**Optimize:**\n```bash\n# Run with parallel compilation\ncd android\n./gradlew assembleDebug --parallel\n\n# Use daemon for faster builds\necho \"org.gradle.daemon=true\" >> gradle.properties\n```\n\n---\n\n## Verifying APK\n\n### Check APK contents\n```bash\nunzip -l app-release.apk | head -20\n```\n\n### Verify signing\n```bash\njarsigner -verify -verbose -certs app-release.apk\n```\n\n### Check size\n```bash\nls -lh app-release.apk\n```\n\n### Analyze with bundletool\n```bash\nbundletool dump manifest --bundle=app-release.aab\n```\n\n---\n\n## Distribution Options\n\n### 1. Google Play Store\n- **Best for:** Widest reach\n- **Cost:** Free (plus developer account $25)\n- **Process:** Upload AAB/APK → Review → Publish\n- **Time:** 2-4 hours review time\n\n### 2. Direct APK Distribution\n- **Best for:** Internal/beta testing\n- **Cost:** Free\n- **Process:** Share APK link → User downloads → Install\n- **Risk:** Users must enable \"Unknown Sources\"\n\n### 3. Alternative App Stores\n- Amazon Appstore\n- Samsung Galaxy Store\n- F-Droid (open source)\n- Aptoide\n\n### 4. Beta Testing (Google Play)\n- **Best for:** Getting user feedback\n- **Setup:** Internal test → Closed beta → Open beta → Production\n\n---\n\n## Release Checklist\n\nBefore releasing to production:\n\n- [ ] All features tested on multiple devices\n- [ ] No console errors or warnings\n- [ ] ProGuard minification enabled\n- [ ] Resources shrinking enabled\n- [ ] Privacy policy created\n- [ ] Permissions justified\n- [ ] App icon created (192x192 minimum)\n- [ ] APK/AAB signed\n- [ ] Version code incremented\n- [ ] Version name updated in build.gradle\n- [ ] Changelog prepared\n- [ ] Screenshots prepared (for Play Store)\n\n---\n\n## Version Management\n\nUpdate version in `android/app/build.gradle`:\n\n```gradle\ndefaultConfig {\n    versionCode 1  // Integer (must increase each release)\n    versionName \"1.0.0\"  // User-readable version\n}\n```\n\n**Versioning scheme:** `MAJOR.MINOR.PATCH`\n- `1.0.0` - Initial release\n- `1.0.1` - Bugfix\n- `1.1.0` - New features\n- `2.0.0` - Breaking changes\n\n---\n\n## Additional Resources\n\n- [Android Build System Documentation](https://developer.android.com/build)\n- [Google Play Console Help](https://support.google.com/googleplay/android-developer)\n- [APK Signing Documentation](https://developer.android.com/about/versions/pie/android-9.0-changes-28#prefer-apk-signing)\n- [Gradle Build Tool](https://gradle.org/)\n
