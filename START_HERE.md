Copy MP4/MKV files to device storage: `/storage/emulated/0/Movies/`\n2. Ensure they have audio codecs: EAC3, AC3, AAC, MP3, FLAC, or Opus\n3. Use file manager or ADB to copy files\n\n### Create/sign release APK\n1. Follow APK_BUILD_GUIDE.md → Signing APK section\n2. Generate keystore: `keytool -genkey -v -keystore my.keystore ...`\n3. Update build.gradle with keystore details\n4. Build: `./gradlew assembleRelease`\n\n### Check audio codec of a video\n```bash\nffprobe -v error -select_streams a:0 -show_entries stream=codec_name your-video.mp4\n```\n\n### Convert video to EAC3 audio\n```bash\nffmpeg -i input.mp4 -c:v copy -c:a eac3 -b:a 448k output.mp4\n```\n\n## 🐛 Troubleshooting\n\n**\"npm command not found\"**\n- Install Node.js from https://nodejs.org/\n\n**\"ANDROID_HOME not set\"**\n- Windows: Set environment variable in System Properties\n- Mac/Linux: Add to ~/.bashrc or ~/.zshrc:\n  ```bash\n  export ANDROID_HOME=/path/to/android-sdk\n  ```\n\n**\"Gradle build failed\"**\n- Check `android/local.properties` exists with SDK paths\n- Run: `cd android && ./gradlew clean && ./gradlew assembleDebug`\n\n**\"App won't start\"**\n- Clear cache: `npm start --reset-cache`\n- Ensure emulator/device is connected: `adb devices`\n- Check Android SDK version (API 21+)\n\n**See full troubleshooting in README.md**\n\n## 💾 Storage & File Size\n\n| Item | Size | Notes |\n|------|------|-------|\n| node_modules | ~500 MB | Development only |\n| Debug APK | ~60-80 MB | For testing |\n| Release APK (universal) | ~26-32 MB | For distribution |\n| Release APK (arm64-v8a) | ~15-18 MB | 64-bit only |\n| Release APK (armeabi-v7a) | ~14-17 MB | 32-bit only |\n\n**Tip:** Use split APKs to reduce size per device!\n\n## 🎨 Customization\n\n### Change app name\n1. `app.json` → displayName\n2. `package.json` → name\n3. `android/app/src/main/res/values/strings.xml` → app_name\n\n### Change colors\n1.
