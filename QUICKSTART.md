# Quick Start Guide\n\n## 5-Minute Setup\n\n### Step 1: Install Dependencies (1 minute)\n\n```bash\ncd VideoPlayerApp\nnpm install\n```\n\n### Step 2: Connect Android Device/Emulator\n\nMake sure you have:\n- Android Emulator running, OR\n- Physical device connected via USB with USB debugging enabled\n\nVerify connection:\n```bash\nadb devices\n```\n\n### Step 3: Start Development Server (1 minute)\n\n```bash\nnpm start\n```\n\nThis starts the Metro bundler. Keep this terminal open.\n\n### Step 4: Run on Device (30 seconds)\n\nIn a new terminal:\n```bash\nnpm run android\n```\n\nThe app will build and install on your device.\n\n## Building APK\n\n### Debug APK (for testing)\n\n```bash\ncd android\n./gradlew assembleDebug\n```\n\nFind APK at: `android/app/build/outputs/apk/debug/app-debug.apk`\n\n### Release APK (for distribution)\n\n```bash\ncd android\n./gradlew assembleRelease\n```\n\n## Testing Video Files\n\n### Using Sample Videos\n\n1. Place video files in: `/storage/emulated/0/Movies/`\n2. Ensure files have these extensions: `.mp4`, `.mkv`, `.avi`, `.mov`\n\n### Supported Audio Codecs\n\n- **EAC3** (.ec3, .eac3) - Best quality surround\n- **AC3** (.ac3) - Standard surround\n- **AAC** (.aac, .m4a) - iTunes/mobile format\n- **MP3** (.mp3) - Universal format\n- **FLAC** (.flac) - Lossless quality\n- **Opus** (.opus, .ogg, .webm) - Modern codec\n\n## Troubleshooting\n\n### App won't start\n```bash\nnpm start --reset-cache\n```\n\n### \"error: SDK location not found\"\n```bash\necho \"sdk.dir=/path/to/android-sdk\" > android/local.properties\n```\n\n### Video won't play\n1. Verify file format: `ffprobe video.mp4`\n2. Check permissions: Settings > Apps > VideoPlayer > Permissions\n3. Try different video format\n\n## Next Steps\n\n1. **Add Custom Videos**: Copy video files to device storage\n2. **Add Subtitles**: Place .vtt or .srt files alongside videos\n3. **Customize UI**: Edit colors in `src/components/VideoPlayer.tsx`\n4. **Build for Release**: Follow signing process in main README\n\n## Common Commands\n\n```bash\n# Start metro server\nnpm start\n\n# Run on Android\nnpm run android\n\n# Build debug APK\ncd android && ./gradlew assembleDebug\n\n# Build release APK\ncd android && ./gradlew assembleRelease\n\n# Clear cache\nnpm start --reset-cache\n\n# Lint code\nnpm run lint\n\n# Run tests\nnpm test\n```\n\nHappy coding! 🎬\n
