Key Files Explanation\n\n### Source Code\n\n#### `src/App.tsx`\n- Main application component\n- Entry point for all screens\n- No styling here; delegates to HomeScreen\n\n#### `src/screens/HomeScreen.tsx`\n- Main home screen UI\n- Displays codec information\n- Lists features and actions\n- Can display local videos\n- Navigation between screens\n\n#### `src/components/VideoPlayer.tsx`\n- Core video player component\n- Features:\n  - Play/Pause controls\n  - Seek functionality with timeline\n  - Volume control\n  - Playback speed control\n  - Subtitle support\n  - Fullscreen mode\n  - Auto-hide controls\n\n#### `src/components/Playlist.tsx`\n- Playlist management component\n- Previous/Next video navigation\n- Show/hide playlist overlay\n- Select video from list\n\n#### `src/types/video.ts`\n- TypeScript interfaces\n- `VideoItem` - Video file metadata\n- `SubtitleTrack` - Subtitle information\n- `PlaylistItem` - Playlist metadata\n- `PlayerState` - Player state management\n- `AudioCodecInfo` - Codec information\n\n#### `src/utils/videoUtils.ts`\n- Utility functions\n- `SUPPORTED_AUDIO_CODECS` - Codec definitions\n- `formatTime()` - Convert seconds to HH:MM:SS\n- `getVideoExtension()` - Extract file extension\n- `detectAudioCodec()` - Detect codec from filename\n- `isCodecSupported()` - Check codec support\n- `parseSubtitleUri()` - Parse subtitle metadata\n\n### Android Configuration\n\n#### `android/app/build.gradle`\n- App-level build configuration\n- ExoPlayer dependencies for EAC3, AC3, FLAC, Opus\n- APK configuration (split by architecture)\n- Signing configuration\n- Build types (debug/release)\n\n#### `android/build.gradle`\n- Project-level build configuration\n- Android SDK version settings\n- Repository configuration\n- Gradle plugins\n\n#### `android/app/AndroidManifest.xml`\n- App manifest\n- Permissions (READ_EXTERNAL_STORAGE, INTERNET, VIBRATE, etc.)\n- Activities\n- Intent filters\n\n#### `android/app/proguard-rules.pro`\n- ProGuard minification rules\n- Keeps React Native and ExoPlayer classes\n- Optimization settings\n\n### Configuration Files\n\n#### `package.json`\n- Node.js dependencies\n- react-native (0.73.0)\n- react-native-video (5.2.1)\n- TypeScript (5.0.4)\n- Build scripts\n\n#### `tsconfig.json`\n- TypeScript compiler options\n- Strict mode enabled\n- ES2020 target\n- JSX as React Native\n\n#### `babel.config.js`\n- Babel transpiler configuration\n- Uses Metro preset for React Native\n\n#### `metro.config.js`\n- Metro bundler configuration\n- Used to bundle JavaScript for React Native\n\n#### `.env.example`\n- Environment variables template\n- Copy to `.env` and customize\n- Includes: ANDROID_SDK_PATH, JAVA_HOME, DEBUG flag\n\n### Setup & Documentation\n\n#### `README.md`\n- Comprehensive documentation\n- Installation steps\n- Audio codec details\n- Usage examples\n- Troubleshooting guide\n- Version information\n\n#### `QUICKSTART.md`\n- Quick 5-minute setup guide\n- Common commands\n- Quick troubleshooting\n\n#### `APK_BUILD_GUIDE.md`\n- APK building process\n- Debug vs Release builds\n- APK signing with keystore\n- Size optimization\n- Distribution options\n- Release checklist\n\n#### `AUDIO_CODEC_GUIDE.md`\n- Detailed audio codec information\n- When to use each codec\n- Codec detection methods\n- Android version support\n- Performance considerations\n- Codec conversion commands\n\n#### `setup.sh` / `setup.bat`\n- Automated setup scripts\n- Checks prerequisites\n- Installs dependencies\n- Linux/Mac (setup.sh) or Windows (setup.bat)\n\n## Development Workflow\n\n### Edit Files\n1. Modify React components in `src/`\n2. Update Android config in `android/app/`\n\n### Build & Test\n1. Run `npm start` - starts Metro bundler\n2. Run `npm run android` - builds and installs on device\n\n### Build APK\n1. `cd android`\n2. `./gradlew assembleDebug` - debug APK\n3. `./gradlew assembleRelease` - release APK\n\n## Adding New Features\n\n### Add a new video format support\n1. Update `android/app/build.gradle` - add ExoPlayer extension\n2. Update `src/utils/videoUtils.ts` - add codec mapping\n3. Update `AUDIO_CODEC_GUIDE.md` - document format\n\n### Add a new player control\n1. Create UI in `src/components/VideoPlayer.tsx`\n2. Update `PlayerState` in `src/types/video.ts` if needed\n3. Handle state updates in component\n\n### Add a new screen\n1. Create file in `src/screens/`\n2. Import and use in `src/App.tsx` or navigation\n3. Update navigation state if needed\n\n## Dependencies Overview\n\n### Core\n- **react-native** (0.73.0) - Mobile app framework\n- **typescript** (5.0) - Type-safe JavaScript\n\n### Video Playback\n- **react-native-video** (5.2.1) - High-level video API\n- **react-native-orientation-locker** (1.7.0) - Screen rotation control\n- **@react-native-community/slider** (4.4.2) - Seek and volume sliders\n- **react-native-fs** (2.20.0) - File system access\n\n### Build & Development\n- **ExoPlayer** (2.18.7) - Android media player with EAC3 support\n- **Babel** (7.20.12) - JavaScript transpiler\n- **Jest** (29.5.0) - Testing framework\n- **ESLint** (8.42.0) - Code quality\n\n## File Size Reference\n\n| Item | Size |\n|------|------|\n| Debug APK | ~60-80 MB |\n| Release APK (universal) | ~26-32 MB |\n| Release APK (arm64-v8a) | ~15-18 MB |\n| Release APK (armeabi-v7a) | ~14-17 MB |\n\n## Next Steps After Setup\n\n1. ✅ Run setup script (`setup.sh` or `setup.bat`)\n2. ✅ Run `npm start` to start development server\n3. ✅ Run `npm run android` to test on device\n4. 📝 Add your video files to device storage\n5. 🎨 Customize UI colors and controls\n6. 🏗️ Build debug APK with `./gradlew assembleDebug`\n7. 📦 Create signed release APK for distribution\n8. 🚀 Upload to Play Store or distribute directly\n\n## Customization Guide\n\n### Change App Colors\nEdit `src/components/VideoPlayer.tsx` and `src/screens/HomeScreen.tsx`:\n- Primary color: `#FF6B35` → Your color\n- Background: `#0d0d0d` → Your color\n\n### Change App Name\n1. `app.json` - displayName\n2. `android/app/src/main/res/values/strings.xml` - app_name\n3. `package.json` - name\n\n### Change Package Name\n1. `app.json` - package name (if added)\n2.
